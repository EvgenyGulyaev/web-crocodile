# Крокодил — испорченный рисунок

Клиент игры для 3–12 человек: Vite, TypeScript, HTML Canvas, без UI-библиотек.

Сайт: [draw.wedding-en.ru](https://draw.wedding-en.ru/). [Бэкенд, API и правила игры](https://github.com/EvgenyGulyaev/drawingService/blob/main/docs/backend.md). [Обслуживание сервера](https://github.com/EvgenyGulyaev/drawingService/blob/main/docs/deployment.md).

## Как проходит игра

Хозяин создаёт комнату и отправляет ссылку друзьям. Каждый открывает её на своём устройстве и нажимает «Готов». После готовности всех каждый придумывает тему; затем участники по очереди рисуют полученный текст и описывают полученный рисунок. Каждый рисует каждую тему, включая собственную: при N игроках получается 2N этапов. Переход к следующему этапу происходит после всех ответов, таймера нет. В финале открываются полные истории превращений.

Если игрок отключился, партия ждёт его возвращения. Хозяин может прервать её новой игрой. Ссылка содержит код комнаты; токен игрока остаётся в его браузере.

## Где находится код

- [src/main.ts](../src/main.ts) — экраны, запросы API, опрос состояния, сессия и черновики.
- [src/canvas.ts](../src/canvas.ts) — холст 1024×768, мышь и сенсорный ввод, отмена и экспорт PNG.
- [src/types.ts](../src/types.ts) — типы игрового состояния.
- [src/style.css](../src/style.css) — оформление и адаптация под экран.
- [tests/game.cjs](../tests/game.cjs) — проверка полной партии в независимых браузерных сессиях.

Команды ниже выполняются из корня `web-crocodile`.

## Запуск

Нужен Node.js 22.12+ или 24+ и запущенный игровой API на порту 8091.

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Для игры с телефонов в одной сети используйте IP компьютера, например `http://192.168.1.10:5173`. Ссылка-приглашение использует адрес, по которому открыта страница. Каждый игрок открывает ссылку в своём браузере; вкладки одного браузера разделяют сохранённую сессию.

Vite проксирует `/api/game` на `http://127.0.0.1:8091`. Другой адрес:

```sh
GAME_API_TARGET=http://127.0.0.1:8091 npm run dev
```

## Сборка

```sh
npm run build
```

Команда проверяет strict TypeScript и собирает `dist/`. В production настройте reverse proxy `/api/game` на игровой API. Токен игрока хранится только в localStorage и передаётся в Authorization; в приглашении — только код комнаты. Черновики сохраняются на устройстве до отправки. В LAN без HTTPS ссылку можно выделить и скопировать вручную. Шрифты загружаются из Google Fonts; при отсутствии сети используются локальные резервные шрифты.

## Автодеплой

`.github/workflows/deploy.yml` собирает фронтенд после push в `main`; доступен и ручной запуск в Actions. Нужны repository secrets `CROCODILE_SSH_KEY` (отдельный ключ пользователя `crocodile-deploy`) и `CROCODILE_HOST_FINGERPRINT` (SHA256 fingerprint SSH-хоста).

Артефакты загружаются в уникальный каталог `/opt/crocodile/incoming/web-<run>-<attempt>-<sha>` на `95.181.224.178`. Установленный серверный скрипт `/usr/local/bin/deploy-crocodile` переключает релиз атомарно, сохраняет текущий API и проверяет HTML через HTTPS. При ошибке возвращает прежний релиз. Nginx и API при выкладке фронтенда не перезапускаются. После успешной проверки остаётся только текущий релиз, старые релизы и assets удаляются. Уже открытой вкладке может потребоваться обновление страницы.

Скрипт находится в `drawingService/deploy`, инструкции — в [drawingService/docs/deployment.md](https://github.com/EvgenyGulyaev/drawingService/blob/main/docs/deployment.md). Данные комнат и рисунков остаются в `/var/lib/crocodile/game.db` вне релизов.

## Проверка полной партии

`tests/game.cjs` проходит игру в трёх независимых браузерных сессиях, включая мобильное касание, сохранение черновиков после перезагрузки, скрытые/финальные изображения, уход хозяина и новую партию. Нужны работающие frontend/API и установленный Playwright с Chromium. Можно использовать Playwright из существующего инструментария через `PLAYWRIGHT_MODULE` (абсолютный путь к пакету):

```sh
PLAYWRIGHT_MODULE=/Users/evgeny/.agents/skills/playwright-skill/node_modules/playwright node tests/game.cjs
```

На другой машине с установленным в проекте Playwright: `node tests/game.cjs`. `GAME_URL` меняет адрес сайта; по умолчанию `http://localhost:5173`. Тест открывает отдельный браузер и не использует личный профиль. Скриншоты результатов сохраняются в `/tmp/crocodile-results.png` и `/tmp/crocodile-mobile.png`.
