# Крокодил — испорченный рисунок

Игра для 3–12 человек: каждый рисует каждую тему. Фронтенд на Vite, TypeScript и HTML Canvas.

Сайт: [draw.wedding-en.ru](https://draw.wedding-en.ru/).

Документация находится в **[docs](docs/README.md)**: правила игры, структура клиента, запуск, сборка, деплой и проверка полной партии.
